# Day 0 — Setup

**Google Classroom assignment**
**Points:** 10
**Due:** 2 days before Day 1
**Submit:** a link to your GitHub repository, and a screenshot of `node --version`

---

Before the first class, get your tools ready. This takes about 45 minutes. You need **two** accounts: GitHub and Railway. That is all.
If you get stuck for more than 20 minutes on any step, message the instructor —
do not spend three hours on it alone.

## Checklist

- [ ] **Node.js** installed. Open a terminal and run `node --version`. You should see `v20` or higher.
- [ ] **Editor** installed — VS Code or Cursor.
- [ ] **AI agent** installed and signed in. Ask it "hello" and get a reply back.
- [ ] **GitHub account** created.
- [ ] **A repository** created, named `expense-tracker`, set to Public.
- [ ] **The starter template** cloned into it (link posted in Classroom).
- [ ] **Railway account** created — sign up *with your GitHub account*, not with email.
- [ ] **Instructor added as a collaborator** on your repository (GitHub → Settings → Collaborators).
- [ ] **One commit pushed** to your repository, containing a `README.md` with your name in it.

## Done when

Your GitHub repository page shows at least one commit, and `node --version` prints a version number.

## Submit

1. The link to your `expense-tracker` repository
2. A screenshot of your terminal showing `node --version`

## Why the instructor needs access

Twice in this course your instructor will change your code on purpose: in Day 4 they
break your own app so you can practise finding the fault, and in Day 5 they plant a
change for you to catch in a diff. Both need write access to your repository.

## Note

You will use this one repository for the entire course. Do not create a new one later.
In week 3 we will read your commit history together.
