# Completion Markers — Not Pass/Fail

Course 0 is an **inspiration course**. There is no pass/fail grading. These are **completion markers** — evidence that students have engaged honestly with the material.

---

## Why "markers" instead of "rubric"

Hein's design decision (2026-11-03):

> Course 0 is designed to **spark curiosity** that leads to Course 1, not to **gate students** from advancing. A hard rubric creates fear; markers create reflection.

The old v1 syllabus used a hard rubric with oral exam and vibe-coder fail. That's archived. v2 uses soft markers.

---

## The 4 Markers

| # | Marker | Evidence (end of Day 8) |
|---|---|---|
| 1 | **Habit Tracker is live** | GitHub Pages URL that loads |
| 2 | **News App is live** | GitHub Pages URL that loads |
| 3 | **3+ real users across both apps** | User quotes in homework submissions |
| 4 | **Can explain what their code does** | 3-min Day 8 presentation to classmates |

---

## Marker 1 — Habit Tracker is live

**Evidence**: URL opens, shows the Habit Tracker, checkboxes can be checked

**How to check**: Teacher opens URL. If it loads, marker met.

**If it doesn't**: Student might need help re-deploying. Not a fail — a coaching moment.

---

## Marker 2 — News App is live

**Evidence**: URL opens, fetches data from Hein's API, displays articles

**How to check**: Teacher opens URL. Articles display within 5 seconds.

**If API is down and student used backup JSON**: still met. "Fetches data" is the skill, not "fetches from exactly this URL."

---

## Marker 3 — 3+ real users

**Evidence**: 3 or more user quotes (across both apps combined) in Day 5 and Day 8 homework

**Who counts as "real users"**:
- ✅ Family members
- ✅ Friends outside this course
- ✅ Classmates from school/work (not this course)
- ✅ Online community members
- ❌ Classmates in this current cohort
- ❌ Fake accounts the student made themselves

**If student struggles**: 2 real + 1 "pending" is acceptable. Day 8 post-course homework gives them another week to recruit users.

---

## Marker 4 — Can explain code

**Evidence**: Day 8 showcase. Each student presents both apps, 3 min each. Narrates what they built and names at least:
- What the app does
- How the data is stored (localStorage for Habit, API for News)
- One feature they're proud of
- One thing they'd change

**No oral exam, no "name every column"**. Just: can they talk about their own work with pride and specifics?

**If a student is extremely shy or silent**: ask them 2 questions one-on-one after class:
1. "Show me a line of your code and tell me what it does."
2. "What's one thing you learned you didn't know on Day 1?"

If they can answer either, marker met.

---

## What NOT to grade on

- Code quality (AI generated it)
- Visual design (subjective)
- Feature count
- Lines of code
- Research notes polish
- Reflection grammar

These are **not** signals of learning in Course 0. Shipping + explaining is.

## What to tell students at end of course

**For students who hit all 4 markers**:
> *"သင် Course 0 ကို ပြီးစေပြီ။ သူတို့ သဘောပေါက်ထား, deploy လုပ်တတ်ပြီ, user တွေ ရှိ, ကိုယ့် code ကိုယ့်ဖာသာ ပြောပြနိုင်။ Course 1 စဖို့ ready။"*

**For students who hit 3 of 4**:
> *"သင် Course 0 ကို ပြီးစေပြီ။ [missing marker] က နောက်မှ ထပ်လုပ်လို့ ရတယ်။ ဒါပေမဲ့ Course 1 စရင်လည်း ပြဿနာ မရှိ။"*

**For students who hit <3**:
> *"သင် Course 0 ကို ဘေးချိတ်ပြီ ဒါပေမဲ့ 50% ပဲ ပြီးသေးတယ်။ Course 1 မသွားခင် ဒီဟာတွေ ပထမဆုံး လုပ်: [specific missing items]."*

Always honest. Always kind.

---

## No certificates for incomplete work

If theBuilderPros issues certificates:

- Full completion (4/4 markers) → certificate
- Partial completion → "letter of participation" or similar, not certificate
- Dropped out → no certificate

**Never issue a certificate to someone who didn't ship.** The certificate's value depends on this.

---

## Realistic expected outcomes (per 10 students)

| Outcome | Expected count |
|---|---|
| All 4 markers | 5-7 |
| 3 markers (missing 1) | 2-3 |
| 2 markers | 1-2 |
| Dropped out | 0-1 |

**5-7 full completions out of 10 is a good result** for a 36-hour beginner course taught by a first-time teacher. Don't inflate.

---

## About the archived v1 "pass/fail rubric"

The old v1 syllabus used a strict 4-criteria pass/fail with oral exam ("explain your Supabase table columns"). That design was over-engineered for an inspiration course. Hein's confirmed decision: **inspiration, not gating.**

Do not restore v1's rubric structure.
