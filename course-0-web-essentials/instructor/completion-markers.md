# Completion Markers — Soft, Not Pass/Fail

Course 0 is an **inspiration course**. These are markers of honest engagement, not pass/fail gates.

---

## Only Capstone 2 (News App) is formally marked

Habit Tracker (Days 1-8) is a **practice vehicle** — not graded. Students who get stuck on fundamentals finish Habit Tracker during Capstone 2 days.

The 4 markers apply to **News App only**.

---

## The 4 Markers

| # | Marker | Evidence |
|---|---|---|
| 1 | **News App is live** | GitHub Pages URL loads |
| 2 | **Fetches from API** | Articles appear from Hein's API |
| 3 | **3+ real users** | Quotes in Day 11-12 submissions |
| 4 | **Can explain code** | Day 12 presentation (3 min, own words) |

---

## Marker 1 — News App is live

**Check**: open URL. If articles load (within 5 seconds), met.

**If URL dead or broken**: coaching, not failing. Help fix.

---

## Marker 2 — Fetches from API

**Check**: F12 → Network tab → see `news.json` request succeeding.

**If API fallback used (local `news.json`)**: still met. Lesson is "fetch from somewhere", not "specifically from this URL."

---

## Marker 3 — 3+ real users

**Who counts**:
- ✅ Family, friends, coworkers
- ✅ Online community members
- ❌ Classmates in this cohort
- ❌ Fake accounts

**Grace**: 2 real + 1 pending within a week OK.

---

## Marker 4 — Can explain code

**Check**: Day 12 presentation (3 min).

**What student should say**:
- What News App does (one sentence)
- Favorite feature (specific, not generic)
- One user feedback quote
- What they'd add next

**No oral exam**. No "name every column." Just: can they talk about their work with pride and specifics?

**If very shy**: 2-question 1-on-1 after class:
1. "Show me a line of code, tell me what it does"
2. "What did Day X teach you?"

If they answer either, marker met.

---

## What NOT to grade on

- Code quality (AI wrote it)
- Design (subjective)
- Feature count
- Research write-up polish
- Grammar

These are not learning signals in Course 0.
