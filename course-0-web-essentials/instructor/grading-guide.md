## Part 1 — Completion Markers


---

## Only Capstone 2 (News App) is formally marked

Habit Tracker (Days 1-8) is a **practice vehicle** — not graded. Students who get stuck on fundamentals finish Habit Tracker during Capstone 2 days.

The 4 markers apply to **News App only**.

---

## The 4 Markers

| # | Marker | Evidence |
|---|---|---|
| 1 | **News App is live** | GitHub Pages URL loads |
| 2 | **Fetches from API** | Articles appear from Hein's API |
| 3 | **3+ real users** | Quotes in Day 11-12 submissions |
| 4 | **Can explain code** | Day 12 presentation (3 min, own words) |

---

## Marker 1 — News App is live

**Check**: open URL. If articles load (within 5 seconds), met.

**If URL dead or broken**: coaching, not failing. Help fix.

---

## Marker 2 — Fetches from API

**Check**: F12 → Network tab → see `news.json` request succeeding.

**If API fallback used (local `news.json`)**: still met. Lesson is "fetch from somewhere", not "specifically from this URL."

---

## Marker 3 — 3+ real users

**Who counts**:
- ✅ Family, friends, coworkers
- ✅ Online community members
- ❌ Classmates in this cohort
- ❌ Fake accounts

**Grace**: 2 real + 1 pending within a week OK.

---

## Marker 4 — Can explain code

**Check**: Day 12 presentation (3 min).

**What student should say**:
- What News App does (one sentence)
- Favorite feature (specific, not generic)
- One user feedback quote
- What they'd add next

**No oral exam**. No "name every column." Just: can they talk about their work with pride and specifics?

**If very shy**: 2-question 1-on-1 after class:
1. "Show me a line of code, tell me what it does"
2. "What did Day X teach you?"

If they answer either, marker met.

---

## What NOT to grade on

- Code quality (AI wrote it)
- Design (subjective)
- Feature count
- Research write-up polish
- Grammar

These are not learning signals in Course 0.

---

## Part 2 — Google Classroom Setup


---

## Setup (before Day 1)

1. Create new class: `Course 0 — Web Essentials — [Cohort]`
2. Invite students (Gmail addresses)
3. Create 12 topics (one per day):
   - Day 1 — HTML & GitHub
   - Day 2 — CSS
   - Day 3 — JS Variables
   - Day 4 — Functions & Conditions
   - Day 5 — Loops
   - Day 6 — DOM & Events
   - Day 7 — localStorage
   - Day 8 — Fetch
   - Day 9 — Capstone 2 Begins
   - Day 10 — Features
   - Day 11 — Code Review
   - Day 12 — Showcase

4. Create 12 assignments (copy from each day's `homework.md`)

---

## Assignment settings

- **Points**: 10
- **Due**: 8pm evening before next class
- **Submission type**: text + links + optional images

---

## Submission rules

**URLs + text + images** only. No zip files.

Valid:
- Live URLs
- Text submissions (reflections, research notes)
- Screenshots

Not valid:
- Project files
- Code uploads

---

## What Classroom can grade

Only Markers 1-2 (URLs). Markers 3-4 are in-person.

| Marker | Role |
|---|---|
| 1 — News App live | Teacher opens URL |
| 2 — Fetches API | Teacher checks Network tab |
| 3 — 3+ users | Teacher reads submission quotes |
| 4 — Explains code | Day 12 in-person |

---

## Weekly flow

| Day | Action |
|---|---|
| 1 | Post Day 1 HW |
| 2 | Day 1 HW due 8pm night before. Review 10 min of class. Post Day 2 HW. |
| 3-11 | Same pattern |
| 12 | Post post-course HW (1 week deadline) |

---

## Grading

Markers 1-3: 10/10 if present.
Marker 4: comment after Day 12 showcase.

Example comment:
> *"Day 12 presentation: confident, named fetch + category filter correctly."*

---

## Attendance

Classroom doesn't track. Keep separate log.

Guidance:
- Missing 1 day → self-study + instructor check-in
- Missing 2+ → makeup needed
- Missing Day 12 → cannot pass without reschedule

---

## Privacy

- URLs sharable within class
- Not external without consent
- Screenshots may have personal data

---

## Quality signals

**Good** (real engagement):
- Specific details
- Honest confusion
- Real user quotes

**Bad** (AI-written):
- Generic phrases
- Perfect grammar from a struggling student
- No specific features mentioned

**Response**: 1-on-1 about submission. If they explain, OK.
