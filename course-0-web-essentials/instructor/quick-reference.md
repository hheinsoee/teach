## 90-min class structure (flipped)

| Block | Min | What |
|---|---|---|
| 🙋 Q&A | 25 | Each student 1 question → board |
| 💬 Discussion | 15 | Top 3 confusions explained |
| 🤝 Live build | 25 | Teacher at AI, students follow |
| ✍️ Label | 10 | Own words, no AI |
| 📋 Wrap | 15 | Next prework + homework + preview |

**Never cut Q&A or Label.**

---

## When silence hits (30 seconds in)

**Wait first** — silence is thinking time.

Then seed questions:
- "When you tried X at home, what happened?"
- "What surprised you in the videos?"
- "Did anything confuse you — even if 'stupid'?"

---

## When I don't know the answer

**Say**: *"ကိုယ်လည်း မသိဘူး — AI နဲ့ အတူတူ ရှာမယ်"*

Open ChatGPT on big screen. Ask question. Read together.

**This is a STRENGTH, not weakness.** Models "learning in real-time."

---

## When class derails on tangent

- Timer alert at 15 min
- "Great question — park that. Back to today."
- Add to "next class" list

## AI co-teacher — quick prompts

### Pre-class (night before)
```
I'm teaching Day [N], topic [TOPIC], 90 min flipped.
Give me: 5 common beginner confusions + 3 Burmese analogies + 1 live build prompt.
```

### During class (silent question)
```
Student just asked "[question]". Day [N], topic [TOPIC], beginner level.
Simple 30-second answer with Burmese analogy.
```

### Post-class (debrief)
```
Day [N] done. Went well: [...]. Struggled: [...].
What to adjust for Day [N+1]?
```

### Emergency (class falling apart)
```
HELP. Day [N], class [DESCRIPTION OF PROBLEM]. [X] min left.
Give me: emotional reset + pivot activity + honest thing to say.
```

## 8 risks — quick mitigation

| Risk | Response |
|---|---|
| Shy student silent | Round-robin, pair-share |
| Didn't do self-study | Catch up during build; flag privately |
| Awkward Q&A silence | Wait 30s + seed question |
| Don't know answer | "Let's ask AI together" |
| Class tangent | "Park it, back to today" |
| Mixed preparation | Teach to middle, help below, challenge above |
| Homework too much | Trim after Week 2 if >5hr average |
| I'm overwhelmed | AI debrief is my safety net |
