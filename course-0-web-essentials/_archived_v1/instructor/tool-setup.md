# Tool Setup — For Students, Before Day 1

Send this list to students at least **1 week before Day 1**. Setup problems kill Day 1 if deferred.

---

## What every student needs

| # | Tool | Why | Account via |
|---|---|---|---|
| 1 | **Chrome** (or Edge) | All tools run in browser | — |
| 2 | **Gmail account** | Used to log in to everything else | gmail.com |
| 3 | **v0.dev** | Day 1-2: UI generation | https://v0.dev — "Sign in with Google" |
| 4 | **Vercel** | Day 1-2: deploy UIs | https://vercel.com — "Continue with Google" |
| 5 | **Lovable** | Day 3-6: full-stack mini-apps | https://lovable.dev — "Sign in with Google" |
| 6 | **Supabase** | Day 3-6: database + auth | https://supabase.com — "Sign in with Google" |
| 7 | **Claude** or **ChatGPT** | Explanations, debugging | https://claude.ai or https://chatgpt.com — free tier OK |

**Total: 1 browser, 5 web accounts, no software to install.** No VS Code. No terminal. No Node.js. Not in Course 0.

## Instructor verification (first 5 min of Day 1)

Walk the room. Ask each student to open:
- v0.dev → are they logged in?
- Vercel → logged in?
- Lovable → logged in?

**Anyone with missing accounts: fix now.** 15 min budget. If more than 2 students aren't set up, run the setup as a group.

## Common setup problems

| Problem | Fix |
|---|---|
| Vercel account requires GitHub | Google works too — use "Continue with Google" |
| Supabase email verification required | Use a real Gmail, check inbox during setup |
| Student doesn't have a Gmail | Create one in 2 min at gmail.com — easier than finding workarounds |
| Student used different emails for each tool | Fine for now; standardize at Day 1 |
| v0 asks for a payment method | Free tier works — skip |

---

## What NOT to install

Course 0 students should **not** have:

- VS Code / Cursor / any code editor
- Node.js
- Git CLI
- Any package manager (npm, bun, pnpm)

If a student insists on installing these (e.g. they're already a developer), fine — but Course 0 does not use them. Course 1 does.

---

## Account hygiene (for the instructor)

Students will create many throwaway Vercel/Supabase projects over 6 days. That's fine on free tiers.

**End of course:** mention they can delete old projects to clean up. Not urgent.
