## အပိုင်း ၂ — Live v0 Demo (၅ မိနစ်)

**(Projector ဖွင့်, v0.dev ကို browser မှာ ဖွင့်။ ကျောင်းသားတွေ screen ကို အာရုံစိုက်)**

> *"ဒါ v0.dev — Vercel ကုမ္ပဏီက လုပ်ထားတဲ့ AI tool။ Prompt တစ်ကြောင်း ရေးလိုက်ရုံပဲ — website ထုတ်ပေးမယ်။ ကြည့်။"*

**(Prompt box ထဲ ရိုက်)**:

```
Build a personal landing page for a teacher named [YOUR NAME].

Include:
- A photo placeholder
- A 2-sentence bio: full-stack developer in Yangon, teaching at theBuilderPros
- 3 links: email, LinkedIn, portfolio

Modern, minimal design.
```

**(Enter နှိပ်။ ကျောင်းသား v0 generate လုပ်တာ မြင်ရ)**

> *"ကြည့်။ **၃၀ စက္ကန့်ထဲ** — website တစ်ခု ထွက်လာပြီ။ သူ့ဘာသာသူ layout ဆွဲ, photo နေရာ ထား, link တွေ ထည့်။*
>
> *ဒါ — ဒီ page က **ကိုယ့် laptop ထဲမှာပဲ** ရှိသေးတယ်။ Internet မှာ မရှိသေးဘူး။ မိတ်ဆွေကို ပြသချင်ရင် — **deploy** လုပ်ရမယ်။"*

**(v0 မှာ "Deploy" button နှိပ်)**

> *"Vercel က hosting service — မြန်မာမှာ 'web ပေါ်မှာ ထားတဲ့ ကုမ္ပဏီ'။ ဒီမှာ login လုပ်, project name ထည့်, deploy နှိပ်။"*

> *"ဒီ ၂ နာရီထဲ — သင်တို့ကိုယ်တိုင် ဒီအတိုင်း လုပ်ကြမယ်။ ကိုယ့်ဖာသာ ကိုယ့် URL ရလာမယ်။*
>

>
> *ကိုယ့် website အရောင်မကြိုက်လည်း — **ship**။ Photo ကြီးလွန်းနေလည်း — **ship**။ Font မကြိုက်လည်း — **ship**။*
>
> *အကြောင်းက — URL ထွက်မှ **"ငါ လုပ်လို့ရတယ်"** ဆိုတဲ့ ခံစားမှု ရမယ်။ Perfect ကို ချိန်ဆနေရင် — ဘာမှ ship မဖြစ်ဘူး။ ဒါ ဒီအတန်းရဲ့ အကြီးဆုံး သင်ခန်းစာ —*
>
> ***"Ugly ships beat beautiful drafts."***
>
> *တကယ့် builder တွေက ဒီအတိုင်း လုပ်ကြတယ်။ အရင် ship, နောက်မှ ပြင်။"*

**(ရပ်။ Energy တက်အောင် ပြုံးပြ)**

> *"OK — accounts စစ်ကြရအောင်။ လက်တွေ့ စမယ်။"*

## အရေးကြီးဆုံး instructor notes

**Energy**:
- Script ကို monotone မဖတ်။ Excitement ပြ။ ကိုယ်ကိုယ်တိုင် ဒီ moment ကို enjoy လုပ်ပြ။
- ကျောင်းသား excited ဖြစ်မယ့်အရာက **ဆရာ excited ဖြစ်မှ**။ ဆရာ bored ဖြစ်ရင် ကျောင်းသား bored ဖြစ်မယ်။

**Timing**:
- ပထမ ၁၅ မိနစ်ကို **၁၇ မိနစ် မကျော်**။ Live demo မှာ Vercel deploy ကြာရင် waiting time က energy ကို ဆွဲချမယ် — ဆရာ story တစ်ခု ပြောပြီး fill လုပ်ထား (ဥပမာ: "ဒီ ၁ မိနစ်မှာ ကိုယ့် ပထမဆုံး deploy လုပ်ခဲ့တုန်းက..." လိုမျိုး)။

**Avoid**:
- ❌ "ဒါ ခက်တယ်" မပြော။ Beginner က instructor က 'ခက်တယ်' ပြောရင် သူတို့ ပိုခက်ထင်မိမယ်။
- ❌ "ဒါ ဘာလို့ အလုပ်လုပ်လဲ ဆိုတော့..." မပြော (Day 1 မှာ)။ "How it works" က Course 1 မှ။
- ❌ Jargon မသုံး။ "frontend", "backend", "server-side rendering" ဘာမှ မပြော။

**Encourage**:
- ✅ "မသိဘူး ပြောတတ်တာ builder skill" — မကြာခဏ ပြန်ပြော။
- ✅ "ugly ships beat beautiful drafts" — ဒီ phrase ကို class တစ်ပတ်လုံး ပြန်ပြော။
- ✅ ဒုတိယ "wait moment" (Vercel deploy) ကို storytelling နဲ့ fill — ဆရာ ကိုယ့် first-time stories။
