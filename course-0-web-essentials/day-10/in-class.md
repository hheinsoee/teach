# Day 10 — In-Class Guide

**Topic**: News App Features (React)

**Pre-class**: You did prework (setup) + self-study (News App Features (React)) + wrote 3 questions

**You bring**: 3 questions, laptop, prepared mindset

**Class time**: 90 min, flipped (you talk 70%, teacher 30%)

---

## 90-min flow

### Phase 1 — Q&A (25 min)

Each student shares 1 question. Teacher writes all on board.

**Don't apologize** for questions. Most are shared by many.

### Phase 2 — Discussion (15 min)

Teacher explains top 3 common confusions with Burmese analogies.

Participate — push back if explanation still confuses.

### Phase 3 — Live Building (25 min)

Teacher uses AI on big screen. You follow in your own files:

1. Modify based on teacher's live code
2. Push changes (git commit → git push)
3. See URL update

**Tweak, don't just copy** — change names, add your own touches.

### Phase 4 — Label (10 min)

Write (no AI, 5 min) — key terms in your own words.

Share with partner (5 min).

### Phase 5 — Wrap + next (15 min)

- Day 11 prework (Viber coming in 2 days)
- Today's homework (`homework.md`)
- Preview Day 11

---

## Rules

1. **Bring 3 questions** — ticket to class
2. **Ask freely** — "I don't know" welcome
3. **No faking** — if didn't do self-study, say so honestly
4. **Phone = Viber only** during class

---

## If came unprepared

Be honest with teacher.

You'll:
- Sit in during Q&A (learn from others)
- Catch up during live build
- Owe extra self-study for Day 11

Don't fake preparedness — flipped relies on honesty.
