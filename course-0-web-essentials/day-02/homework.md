# Day 2 Homework — Research CSS + Try 2 Styles

**Total time**: ~3 hours

---

## Part 1 — Research (1 hour)

Pick 3 CSS properties: `color`, `background`, `font-size`, `padding`, `margin`, `border-radius`, `display`.

For each: watch 1 video, write 2 sentences in your own words.

---

## Part 2 — Build (1-1.5 hours)

### A. Two different styles

Ask AI for 2 completely different designs:
- "Make it look like a notebook — paper feel"
- "Make it look like a modern app — clean, blue accent"

Save each as a screenshot. Pick favorite as final `styles.css`. Push.

### B. Add hover effect

Ask AI: "When I hover over a habit, change color".

### C. Add emoji icons

Ask AI: "Add emoji next to each habit".

### D. Break and fix

Delete `<link rel="stylesheet">` from HTML. Push. See plain page. Restore. Push.

---

## Part 3 — Reflect (0.5 hour)

3-5 sentences:
1. Most useful CSS property?
2. Which prompt worked best?
3. Question you still have?
