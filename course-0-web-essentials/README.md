# Course 0 — Web Essentials

**4 weeks · 8 days · 90 min/day · 12 contact hours · 24 homework hours · 36 hours total**

> A **day** = one 90-min class meeting. There are 8.
>
> Students read code generated by AI. They don't write code by hand. They **understand**, **direct**, and **verify** the AI output.

Taught at **theBuilderPros** workshops as the entry point before Course 1.

## Who this is for

An **absolute beginner** — no programming background, no prior web experience. Comfortable using a computer and able to read basic English. Someone who wants to understand how web apps work and build real things, with AI as their coding partner.

## Who this is **not** for

Someone who wants to become a professional programmer in 36 hours. Programming mastery is Course 1+.

## The promise

> By Day 8, the student has **two live web apps** (a Habit Tracker and a News App) deployed to the internet, can **read the code** that runs them, can **direct AI** to add features, and knows **where to look** when something breaks.

Not a programmer. Not an engineer. An **inspired beginner** — someone who understands code enough to keep learning on their own, ready for Course 1.

## Core principle

> **"Code ကို အဓိက မသင်။ AI ရှိတယ်။ Code ကို သဘောပေါက်ရမယ်, ဖတ်တတ်ရမယ်။"**
>
> *Don't teach code as the primary thing. AI is there. Students must understand code and be able to read it.*

Four skills: **Read · Understand · Direct · Verify.** No syntax drills. No hand-written code from scratch. AI generates; the student reads, understands, modifies, and verifies.

## Projects

### Project 1 — Daily Habit Tracker (Days 1-5)

Browser-only, offline, localStorage persistence. No backend.

**Features**: Add habits (ဘုရားရှိခိုး, စာကျက်, exercise), check off daily, see streaks, data persists.

### Project 2 — News App (Days 6-8)

Browser-only, consumes a public API that Hein pre-builds and hosts.

**Features**: Fetch news articles, display with images/dates, filter by category, click to expand.

**The API is pre-built — students only consume it.** Backend work is Course 1+.

## Outcome

The student can:
- **Read** HTML, CSS, and JavaScript line by line and say what each line does
- **Understand** how a browser runs a web app
- **Direct** AI (ChatGPT, Claude) to generate code for features they want
- **Verify** AI output is correct by reading it + testing it
- **Deploy** code to the internet with Git + GitHub Pages
- **Fetch** data from a server and display it

They will not write code from scratch. They will not design a database. They will not architect a system. Those come later.

If they want those things next, that is [Course 1](../course-1-ai-assisted-fullstack/).
