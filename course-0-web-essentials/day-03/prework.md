# Day 3 — Prework (2 Days Before Class)

Send this to students via Viber/Telegram **2 days before Day 3**.

**Student task time**: 15-20 minutes. Setup only — no learning yet.

---

## Viber/Telegram message template (Burmese)

> *"Day 3 မလာခင် (၂ ရက်ကြို) ဒီ setup တွေ ပြီးထား:*
>
> *1. ဒီ ๒ ရက်က ဖိုင်တွေ (Day 1-2 Habit Tracker) အလုပ်လုပ်သေးလားကြည့်:*
>    - *ကိုယ့် live URL ဖွင့်ကြည့်*
>    - *GitHub Desktop ဖွင့်, uncommitted changes ရှိရင် commit + push*
>
> *2. Chrome DevTools စမ်း:*
>    - *Live URL ကို ဖွင့်*
>    - *F12 နှိပ် (ဒါမှမဟုတ် right-click → Inspect)*
>    - *'Console' tab ကို နှိပ်*
>    - *နောက်နေ့ ည self-study မှာ ဒီ Console မှာ code ရိုက်မယ်*
>
> *3. ChatGPT ဒါမှမဟုတ် Claude ဖွင့်ထား — logged in*
>
> *မနက်ဖြန်ည (Day 3 မတိုင်မီ ည) → self-study.md လုပ်မယ်။*
>
> *Done ဖြစ်ရင် ✅ react ပေး။*
> *Stuck ဖြစ်ရင် message ပြော။"*

---

## What this prework achieves

✅ Day 1-2 work still exists (regression check)
✅ DevTools access ready
✅ AI tool ready
✅ Zero infrastructure friction for Day 3 self-study

---

## Instructor verification

Check Viber reactions:
- ✅ emoji = ready
- ❓ or no reaction = needs follow-up before Day 3

If >30% of cohort hasn't reacted 1 day before class → send reminder.

---

## Common prework problems

| Problem | Fix |
|---|---|
| Live URL doesn't work | Check GitHub Pages settings; may need Pages Source = "GitHub Actions" |
| GitHub Desktop forgot login | Sign in with Google again |
| F12 doesn't open DevTools | Try right-click → Inspect |
| ChatGPT limits reached | Switch to Claude |

---

## If student is new (missed Days 1-2)

- Share Day 1-2 content
- Catch up over weekend before Day 3
- Pair with buddy student in class

Don't delay class for one unprepared student.
