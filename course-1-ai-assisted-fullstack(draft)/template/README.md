# Expense Tracker

## Run it

```
npm install
npm run dev
```

Open http://localhost:3000

## Test it

```
npm test
```

## What is here

| Path | Runs where | What it is |
|---|---|---|
| `server.js` | your server | the web server |
| `public/index.html` | the browser | the page |
| `public/app.js` | the browser | what the page does |
| `public/style.css` | the browser | how it looks |
| `test/` | your machine | tests |

Nothing else. Every file you add from here is one you asked for.
