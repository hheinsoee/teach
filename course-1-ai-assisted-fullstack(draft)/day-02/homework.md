# Homework 2 — Annotate Code

**Google Classroom assignment**
**Points:** 10
**Due:** evening before Day 3
**Submit:** a link to `notes/day-02.md` in your repository

---

## Task

Your instructor has posted 5 short code samples in Classroom.

For each one, write in your own words:

1. What does this code do, overall? (1 sentence)
2. What do these specific lines do? (the marked lines)
3. Which of the 7 things appear in it?
4. What breaks if you delete the marked line?

Write your answers in a new file in your repository: `notes/day-02.md`.
Commit and push it.

## Rules

- You **may** ask the agent to explain a sample.
- You **may not** paste the agent's explanation as your answer.
- If your answer contains a word you cannot define, remove it and write a simpler answer.

An answer like *"it iterates over the collection and transforms each element"* is
worth **zero** if you cannot say what "iterates" means. *"It goes through the list one
at a time and makes a new list"* is worth full marks.

## Done when

- [ ] `notes/day-02.md` exists in your repository and is pushed
- [ ] All 5 samples have all 4 answers
- [ ] Every word in your answers is a word you could explain out loud

## Submit

The GitHub link to your `notes/day-02.md` file.
