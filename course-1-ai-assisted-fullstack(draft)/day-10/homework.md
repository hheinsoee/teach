## Part 1 — Three real tests (5 points)

Tests covering:

1. A negative or non-numeric amount is rejected
2. User A cannot read, edit, or delete user B's expense
3. The monthly total is correct

Three. Not more. Each one must be proven in Part 2.

## Part 2 — Prove every one of them (5 points)

For each test, in `notes/day-10.md`:

| | |
|---|---|
| What I broke | the exact change you made |
| Did the test fail? | yes / no |
| If no, what I did about it | fixed it or deleted it |

**A test you did not break does not count for marks.** Breaking the code is the only
proof that a test does anything.

## Part 3 — The fake tests

From the four in `broken/`:

1. Which two were fake?
2. How did you prove it?
3. What makes a test look real when it is not?

## Done when

- [ ] 5 tests, all passing

- [ ] Any fake test fixed or deleted
- [ ] The three questions answered
