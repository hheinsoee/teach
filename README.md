# theBuilderPros — Teaching Materials

Courses taught by **Hein Soe** at **theBuilderPros** workshops.

---

## ⭐ Course 0 — Web Essentials (ACTIVE)

**Status**: Being taught now (Nov 2026 cohort)
**Audience**: Absolute beginners — no programming background
**Length**: 6 weeks · 12 days × 90 min · **54 hr total** (18 class + 36 homework)
**Produces**: An **inspired beginner** who can read code, direct AI, and ship real web apps

**What students build**:
- Habit Tracker (practice vehicle, Days 1-8)
- News App (Capstone 2, Days 9-12) — with real users

**Core principle**:
> *"Code ကို အဓိက မသင်။ AI ရှိတယ်။ Code ကို သဘောပေါက်ရမယ်, ဖတ်တတ်ရမယ်။"*
>
> Don't teach code as the primary thing. AI exists. Students must understand code and be able to read it.

→ **[Enter Course 0 →](course-0-web-essentials/)**

## 📦 Course 1 — AI-Assisted Full-Stack (FUTURE / ON-DEMAND)

**Status**: Not currently being taught. Opens when:
- Course 0 graduates signal readiness (3+ interested)
- Hein has bandwidth for a smaller cohort (5-8 students)

**Target cohort**: Feb 2027 or later

**Audience**: **Course 0 graduates** who want to go deeper into real-world engineering practice

**Length**: 6 weeks · 12 days × 2 hr · **~60-72 hr total**
**Produces**: A **full-stack builder** able to ship a production app with auth, database, and tests — ready to continue into professional practice

**Real-world focus**:
Course 1 introduces **professional topics** Course 0 doesn't touch:
- Full-stack architecture (frontend + backend + database)
- Authentication and security
- Testing and code review
- Production deployment, logs, monitoring
- Industry workflow (Git diffs, pull requests, debugging)
- Reading other people's code

**Prerequisites (hard)**:
- ✅ Course 0 — Web Essentials complete, OR equivalent self-study
- ✅ Can read HTML, CSS, JavaScript fluently
- ✅ Committed to 60-72 hours over 6 weeks
- ✅ Comfortable with English docs (MDN, Stack Overflow)
- ✅ Attitude: "I want to defend my code, not just ship it"

→ [Course 1 syllabus (reference)](course-1-ai-assisted-fullstack/)

## Which course for whom

| You say... | Course |
|---|---|
| "I want to build and ship my idea with AI help" | **Course 0** |
| "I want to see what code is and make simple web pages" | **Course 0** |
| "I finished Course 0 and want full-stack / real-world" | **Course 1** (when opens) |
| "I want to be a software engineer on a team" | Course 1, then look at Course 2-4 |
| "I'm already a developer wanting AI mastery" | Not this course series |

---

## Honesty policy

- **Course 0 produces an inspired beginner**, not a developer
- **Course 1 produces a full-stack builder**, not a junior engineer
- Later courses (2-4, not yet built) go toward engineering

**Never inflate these claims anywhere.** The courses are honest about what they deliver.
