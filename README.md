# Course 1 — AI-Assisted Full-Stack Development

**6 weeks · 12 days · 2 hours/day · 44 sessions · 24 contact hours · 6–8 h/week homework**

> A **day** is one 2-hour class meeting — there are 12.
> A **session** is a teaching block inside a day — there are more than 12.

> The AI agent writes the code. The student understands it, directs it, verifies it, and owns it.

Every day fits in 120 minutes. Day 9 has pre-work; day 12 depends on class size — see [`instructor/pacing.md`](instructor/pacing.md).

## Outcome

A **full-stack builder** — able to take an idea to production alone.
Not a junior engineer ready for a team codebase. Keep that claim honest everywhere.
