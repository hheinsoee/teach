# Absolute Beginner — Teaching Materials

Courses taught by **Hein Soe** at theBuilderPros workshops.

## Courses

| Course | Audience | Length | Produces |
|---|---|---|---|
| [**Course 0** — Web Essentials](course-0-web-essentials/) | Absolute beginner, no code | 3 weeks · 12h class · 24h homework | A builder with a live mini-app and real users |
| [**Course 1** — AI-Assisted Full-Stack Development](course-1-ai-assisted-fullstack.md) | Someone who finished Course 0 (or equivalent) | 6 weeks · 24h class · 36h homework | A full-stack builder who can read & direct code |

See [`program-roadmap-levels-1-8.md`](program-roadmap-levels-1-8.md) for the long-term 8-level roadmap.

## Which course for whom

> **"I just want to build my idea and put it on the internet."**
> → Course 0. You will not write code. You will ship.

> **"I want to understand the code AI gives me, read it, direct it, fix it."**
> → Course 1. You will not become an engineer, but you will not be helpless either.

> **"I want to be a software engineer and work on a team."**
> → Not yet. Finish Course 1, then look at Courses 2–4 (integration, architecture, scale).

## Honesty

Course 0 produces a **builder**, not a developer.
Course 1 produces a **full-stack builder**, not a junior engineer.
Later courses (2–4) are what take someone toward engineering.

Do not inflate these claims anywhere. The courses are honest about what they do and don't deliver — that is the point.
