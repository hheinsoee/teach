# Day 1 — In Class

## Goal

By the end of today, a web page you made is live on the internet, and you can open it
on your phone.

## The map

Everything you build in this course lives in one of four places:

| Layer | What it is | Example |
|---|---|---|
| Browser | What the user sees and clicks | The page with your expense list |
| Network | How the browser talks to your server | "Give me my expenses" |
| Server | Your code, running on a computer you don't own | Checking you are logged in |
| Database | What is remembered after you close the tab | Your expenses, stored |

Today you touch all four from the outside. Over the next 11 days you build each one.

## Steps

### 1. Start the project

Ask your agent:

> Create a simple one-page website using Express. The page should show my name as a
> heading and one sentence about why I am taking this course. Keep it minimal —
> no extra pages, no extra libraries.

### 2. Run it locally

Ask the agent how to start it. Open the address it gives you (usually `localhost:3000`).

**Before you continue, answer this in your notes:** what does `localhost` mean?
Who else in the room can open your `localhost:3000`?

### 3. Put it on GitHub

Push the code to the `expense-tracker` repository you created in Day 0.

### 4. Deploy

Connect the repository to Railway. Wait for the build. Get your URL.

### 5. Verify

- Open the URL on your **phone**, on mobile data, not classroom WiFi.
- Send it to the person next to you. Have them open it.

That is the difference between `localhost` and production. Write down, in one sentence,
what that difference is.

## If you finish early

Change one thing on the page, push, and watch Railway rebuild. Time how long it takes.
Do **not** start building the expense tracker — that begins in day 6.
