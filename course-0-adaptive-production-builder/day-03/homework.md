# Day 3 Homework — Ship a Second Data Mini-App

## Why this homework exists

In class, you shipped one data-driven mini-app. Today's homework: **ship a different one on a different topic.** Repetition is how the pattern locks in.

By end of this week you'll have shipped **4 mini-apps** total — 2 in class, 2 at home. That's how you get fluent, not through theory.

---

## What to do (3-4 hours)

### Part 1 — Pick a different topic (10 min)

**Do NOT repeat what you built in class.** Pick a different one. Examples:

- Class: todo list → Homework: expense tracker
- Class: notes → Homework: contacts list
- Class: journal → Homework: habit tracker (did I exercise today? yes/no)
- Class: expense tracker → Homework: inventory list

**Keep it small.** One table. One page. One kind of thing to track.

### Part 2 — Build with Lovable + Supabase (90 min)

Prompt structure:

```
Build a [TYPE] app with Supabase.

Each [THING] has:
- [column 1 — e.g. name]
- [column 2 — e.g. date]
- [column 3 — e.g. category]

Features:
- Add a new [THING] with a form at the top
- See all [THINGS] in a list below
- [any extra: delete? mark done? filter?]

Store in Supabase. Mobile-first.
```

Deploy. Open on phone. Add 3-5 rows.

### Part 3 — Verify in Supabase (15 min)

- Open supabase.com → your new project → Table Editor
- See your rows
- Take a screenshot (will be submitted)

### Part 4 — Write reflection (30-45 min)

Submit three things:

**1. The URL** (works when the instructor opens it)

**2. A screenshot** of your Supabase table showing at least 3 rows

**3. Reflection** (3-5 sentences):

- What kind of app did you build?
- What's the name of your Supabase **table**?
- What are the **columns** in your table?
- When you added a row in the app, where did it end up?
- What is one difference between this mini-app and the one you built in class?
