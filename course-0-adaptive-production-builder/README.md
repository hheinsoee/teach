# Course 0 — Adaptive Production Builder

**3 weeks · 6 days · 2 hours/day · 12 contact hours · 24 homework hours · 36 hours total**

> A **day** = one 2-hour class meeting. There are 6.
>
> No code written by the student. Ship a live mini-app in **day 1**. Keep shipping, one per day.

Taught at **theBuilderPros** workshops as the entry point before Course 1.

## Who this is for

An **absolute beginner** — no programming background, no prior web experience. Comfortable using a computer and able to read basic English. Someone who wants to turn an idea into a real app without first spending months on syntax.

## Who this is **not** for

Someone who wants to become a software engineer and read other people's code. That is Course 1.

## The promise

> By class 6, the student has **their own mini-app with real users** — built with AI tools, deployed to the internet, and understood well enough to keep improving.

Not a developer. Not an engineer. A **builder** — someone who can go from idea to live URL alone, using tools that exist today.

## The 6 days

| Day | Title | Core skill | Ships |
|---|---|---|---|
| [1](day-01/) | Bound Your Context, Ship Your First Mini-App | See the whole picture, deploy | 🚀 Landing mini-app |
| [2](day-02/) | Ask Two Questions — Prompt With Precision | Prompting | 🚀 Problem-focused mini-app |
| [3](day-03/) | Stand on Giants — Mini-App With a Database | Data lives somewhere | 🚀 Data-driven mini-app |
| [4](day-04/) | Build for Users — Login & Multi-User | Who is using it | 🚀 Multi-user mini-app |
| [5](day-05/) | Operate Like a Pro — Read Errors, Modify, Ship Again | Fix without an engineer | 🚀 Fixed/improved mini-app |
| [6](day-06/) | 🎓 Your Mini-App to Real Users | Everything | 🎓 Capstone with real users |

**Every day ships a live URL.** That is the rule. If a day ends with nothing live, the day failed.

## Outcome

The student can take an **idea** → **working mini-app on the internet** → **real users**, using AI tools, without writing code.

They will not read JavaScript. They will not debug SQL. They will not know what a function is. That is fine — this course does not promise those things. It promises production.

If they want those things next, that is [Course 1](../course-1-ai-assisted-fullstack/).
